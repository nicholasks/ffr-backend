
# A Digital Menu for restaurants

Back-end created with Django and Front-end using React.js

## Setting up development environment:
 
* Clone this repository
* Install python3 virtual environment: `sudo apt install python3-venv`
* Create a new virtualenv: `python3 -m venv /home/user/ffr-backend`
* Activate it: `source /home/user/ffr-backend/bin/activate`
* Then change to repository directory: `cd /home/user/ffr-backend/`
* Install python requirements: `pip install -r requirements.txt`
* Finally run the development server using:

`python manage.py runserver 8080`
